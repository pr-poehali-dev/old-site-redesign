## 📊 Запуск рекламы - пошаговая инструкция:

1. **Зарегистрируйтесь в Яндекс.Директ:**
   - https://direct.yandex.ru/
   - Войдите через Яндекс ID

2. **Создайте первую кампанию:**
   - Выберите "Текстово-графические объявления"
   - Скопируйте группы объявлений из этого файла
   - Укажите счётчик Метрики: 96856709

3. **Пополните баланс:**
   - Минимум 10 000 ₽ для старта
   - Яндекс даст бонус 3000₽ за первое пополнение

4. **Запустите модерацию:**
   - Проверка займёт 1-3 часа
   - Объявления начнут показываться сразу после одобрения

5. **Отслеживайте результаты:**
   - Яндекс.Директ → Статистика
   - Яндекс.Метрика → Отчёты → Источники
