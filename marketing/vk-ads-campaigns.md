## 🚀 Запуск рекламы VK - пошаговая инструкция

### Шаг 1: Регистрация
1. Откройте: https://vk.com/ads
2. Войдите через VK
3. Создайте рекламный кабинет

### Шаг 2: Установка пикселя
1. Ретаргетинг → Создать пиксель
2. Скопируйте код
3. Добавьте в index.html вашего сайта

### Шаг 3: Создание кампании
1. Создать кампанию → Реклама сайта
2. Выберите цель: "Конверсии"
3. Укажите URL: https://megashlic.ru/
4. Установите бюджет: 10 000 ₽

### Шаг 4: Настройка таргетинга
1. География: Россия, города 100k+
2. Возраст: 25-55
3. Интересы: скопируйте из "Аудитория 1"
4. Устройства: Мобильные и десктоп

### Шаг 5: Загрузка креативов
1. Загрузите изображение с сайта
2. Скопируйте текст из "Креатив 1"
3. Добавьте кнопку "Связаться"
4. Укажите ссылку на сайт

### Шаг 6: Запуск
1. Проверьте все настройки
2. Пополните баланс (минимум 5000 ₽)
3. Отправьте на модерацию
4. Модерация: 1-4 часа
5. Реклама запустится автоматически
